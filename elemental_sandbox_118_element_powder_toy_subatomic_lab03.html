Rendering Technology Comparison (WebGL2 vs WebGPU vs WASM/Native)
API / Approach Shading Language Compute Support Browser Support (2026) Pros Cons
WebGL2 + GLSL GLSL ES 3.0 Fragment ping-pong / Transform Feedback Universal (Desktop & Mobile) Mature, 100% baseline compatibility, fast FBO post-processing (SSAO/Bloom/God Rays). No native compute shaders; state updates require ping-pong textures.
WebGPU + WGSL WGSL / SPIR-V Native Compute Pipelines (`@compute`) Chrome 113+, Edge, Firefox 141+, Safari 26+ Explicit modern GPU control, storage buffers, subgroup ops, 1M+ particles at 120Hz. Requires secure context (HTTPS) and fallback path for legacy devices.
WASM + SIMD + Threads C++/Rust → WASM 128-bit SIMD + `SharedArrayBuffer` Workers All modern browsers (with COOP/COEP headers) Near-native CPU physics speed; reuses C++/Rust solvers (Rapier, Bullet, MPM). Requires Cross-Origin Isolation headers (`COOP`/`COEP`) for `SharedArrayBuffer`.
Continuum, Particle & Hybrid Physics Solvers Matrix
Method Core Formulation Advantages Limitations & 120Hz Mitigation
SPH (Smoothed-Particle Hydrodynamics) Lagrangian particles with radial smoothing kernels $W(\mathbf{x}_i - \mathbf{x}_j, h)$ Mesh-free, natural free-surface splashes, strict mass conservation, trivially parallelizable. $O(n^2)$ naive search mitigated via $O(n)$ Spatial Hashing / Uniform Grid binning.
PIC / FLIP (Fluid-Implicit-Particle) Hybrid: Particles advect; MAC grid solves Pressure Poisson $\nabla^2 p = \nabla \cdot \mathbf{u}$ Zhu–Bridson FLIP blends 95% FLIP velocity deltas + 5% PIC to eliminate numerical dissipation. Requires grid-to-particle (G2P) and particle-to-grid (P2G) transfer passes each substep.
Eulerian Grid (Jos Stam Stable Fluids) Fixed Navier-Stokes grid with semi-Lagrangian back-trace advection & Jacobi projection Unconditionally stable at any timestep $\Delta t$; drives realistic smoke, gas vortices & pressure waves. Vorticity confinement added to counteract numerical diffusion at 120 FPS.
MLS-MPM (Material Point Method) Continuum mechanics on background grid + deformation gradient $\mathbf{F}_p$ on particles Unified solver for granular sand, elastic solids, viscoplastic lava, and fluids with self-collision. Higher ALU load per particle; best paired with WebGPU compute workgroups (`workgroup_size(256)`).

struct Particle {
  pos: vec2<f32>,
  vel: vec2<f32>,
  temp: f32,
  matId: u32,
};
struct SimParams {
  dt: f32,
  gravity: f32,
  wind: f32,
  numParticles: u32,
};
@group(0) @binding(0) var<storage, read_write> particles: array<Particle>;
@group(0) @binding(1) var<uniform> params: SimParams;

@compute @workgroup_size(256)
fn cs_main(@builtin(global_invocation_id) id: vec3<u32>) {
  let i = id.x;
  if (i >= params.numParticles) { return; }
  var p = particles[i];
  // Symplectic Euler integration with gravity + wind drag
  p.vel.y += params.gravity * params.dt;
  p.vel.x += params.wind * 0.05 * params.dt;
  p.pos += p.vel * params.dt;
  // Toroidal or solid boundary clamp
  p.pos = clamp(p.pos, vec2<f32>(1.0, 1.0), vec2<f32>(254.0, 154.0));
  particles[i] = p;
}
2. WebGL2 GLSL ES 3.0 (SSAO + Volumetric God Rays + Normal PBR) #version 300 es 
#version 300 es
precision highp float;
in vec2 v_uv;
uniform sampler2D u_colorTex;
uniform sampler2D u_depthTex;
uniform vec2 u_sunPos;
uniform vec4 u_flags; // x=SSAO, y=GodRays, z=Normals, w=Bloom
out vec4 outColor;

void main() {
  vec4 base = texture(u_colorTex, v_uv);
  float d = texture(u_depthTex, v_uv).r;
  // 1. Screen-Space Ambient Occlusion (8-tap spiral kernel)
  float occ = 0.0;
  if (u_flags.x > 0.5 && d > 0.05) {
    for (int k = 0; k < 8; k++) {
      float a = float(k) * 0.785398;
      vec2 off = vec2(cos(a), sin(a)) * vec2(1.0/256.0, 1.0/156.0) * 1.8;
      if (texture(u_depthTex, v_uv + off).r > d + 0.02) occ += 0.125;
    }
  }
  // 2. Screen-Space Volumetric Raymarching toward Sun
  vec2 delta = (u_sunPos - v_uv) * (1.0 / 16.0);
  vec2 cur = v_uv; float shafts = 0.0;
  for (int s = 0; s < 16; s++) {
    cur += delta;
    shafts += (1.0 - texture(u_depthTex, cur).r) * 0.04;
  }
  outColor = vec4(base.rgb * (1.0 - occ * 0.45) + shafts * u_flags.y, 1.0);
}
